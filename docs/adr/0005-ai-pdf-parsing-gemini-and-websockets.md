# 5. Интеллектуальный парсинг банковских выписок (Gemini API + WebSockets)

* Статус: Принято
* Дата: 2026-07-15

## Контекст и проблематика
Пользователи хотят быстро импортировать историю операций из выписок различных банков (Т-Банк, Сбербанк, Альфа-Банк и т.д.). Банковские PDF-файлы имеют разную верстку и структуру страниц, что делает написание традиционных регулярных выражений (regex/pdf-parser) ненадежным. Кроме того, парсинг больших документов занимает несколько секунд, и обычный HTTP-запрос блокирует клиент или приводит к таймауту.

## Принятое решение
1. **Интеграция ИИ**: Использовать **Google Gemini Flash API** для распознавания содержимого выписки. Инструкция задает структурированный JSON Schema формат ответа, гарантируя строгое соответствие DTO транзакций.
2. **Асинхронность и WebSockets**: При загрузке файла сервер сразу возвращает ответ о принятии задачи и запускает фоновый процесс. Оповещение клиента о прогрессе (загрузка, распознавание, сохранение) и завершении обработки происходит через **WebSockets (Socket.io)**.

## Альтернативы
1. **Традиционный REGEX-парсинг**: Требует поддержки отдельных парсеров под каждый банк и ломается при изменении шаблона выписки банком.
2. **Синхронный HTTP polling**: Постоянный опрос сервера каждые N секунд загружает сеть и создаёт лишние запросы.

## Последствия
### Плюсы
- Высокая точность извлечения даты, суммы, категории и описания независимо от верстки банка.
- Отличный UX: пользователь видит живой статус парсинга в реальном времени.

### Минусы
- Зависимость от внешнего AI API (необходимость обработки лимитов и возможных ошибок сети).
- Потребность в поддержании активного WebSocket-соединения.
